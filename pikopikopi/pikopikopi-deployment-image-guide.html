✅ Task 1 — Foto kopi dari dataset builder

📸

Download 56 foto dari Wikimedia Commons

Script scripts/download_coffee_images.py dijalankan untuk semua 20 jenis kopi. Foto disimpan di data/images/<label>/ dengan 2–3 foto per kelas. Metadata lisensi (CC BY-SA, CC0, dll.) tersimpan di data/coffee_image_metadata.csv.

🏷️

Kredit foto tampil di kartu rekomendasi

Kartu rekomendasi kini menampilkan label "© Wikimedia Commons" di sudut bawah foto (tooltip berisi nama fotografer). Modal detail menampilkan kredit lengkap beserta lisensi di bagian footnote.

🎨

CSS baru: .photo-credit dan .detail-photo-credit

Dua class CSS baru ditambahkan ke static/css/styles.css untuk menampilkan atribusi foto dengan desain pill transparan di atas gambar.

✅ Task 2 — Deployment ke publik

🚀

start.sh — Script startup otomatis

File baru start.sh menjalankan download foto saat first run, kemudian langsung menjalankan uvicorn. Tidak perlu langkah manual setelah deploy.

🐳

Dockerfile diperbarui

CMD diubah dari inline uvicorn menjadi sh start.sh. Dockerfile sudah lengkap untuk Docker deployment ke Render.

🦇

run_local_windows.bat diperbarui

Batch script lokal kini juga mengunduh foto otomatis saat pertama kali dijalankan, menggunakan flag data\.images_downloaded untuk tidak mengulang download.

🗺️ Langkah deployment ke Render.com

Prasyarat: Butuh Git dan akun GitHub untuk mengunggah project. Download Git dari git-scm.com/download/win jika belum terinstall.

Install Git for Windows

Download dari git-scm.com/download/win → install dengan pengaturan default → restart PowerShell/terminal.

Buat repository di GitHub

Login ke github.com → New repository → nama bebas (contoh: pikopikopi) → pilih Private → klik Create.

Push project ke GitHub

Buka PowerShell di folder pikopikopi/:

# Di folder pikopikopi/
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/<username>/pikopikopi.git
git branch -M main
git push -u origin main

Buat Web Service di Render.com

Login ke render.com → New → Web Service → hubungkan GitHub → pilih repo pikopikopi → pilih Runtime: Docker.

Set environment variables

Di tab Environment pada Render:

KeyValue
ADMIN_PASSWORDPassword kuat minimal 12 karakter
SECRET_KEYString random panjang
COOKIE_SECURE1
DATA_DIR/var/data (sudah ada di render.yaml)

Konfigurasi persistent disk

Di tab Disks: Name = pikopikopi-data, Mount Path = /var/data, Size = 1 GB. Catatan: disk hanya tersedia di paid plan (Starter ~$7/bulan).

Deploy dan tunggu health check

Klik Deploy. Build 3–5 menit. Saat first run, start.sh otomatis download foto. Health check /api/health akan green setelah siap. URL format: https://pikopikopi.onrender.com
